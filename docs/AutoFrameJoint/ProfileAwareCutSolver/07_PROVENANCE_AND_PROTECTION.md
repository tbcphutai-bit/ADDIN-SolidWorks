# Provenance and source protection

Evidence levels:

- API_VERIFIED: native FeatureManager identity/order, scalar feature properties, Sketch geometry and reference values that the API actually returned.
- GEOMETRY_VERIFIED: exact temporary B-rep difference, measured volume/Check2, oracle equivalence, interference/distance and recorded Display3/Hide API results.
- INFERRED: semantic region labels, rule extrapolation beyond the documented tests, manufacturing intent not established by a drawing. A user-confirmed policy is recorded separately and does not rewrite historical CAD evidence.

Native before/after BREP streams, original CAD/STEP/PDF/ZIP and complete stock face dumps remain private. Published data includes necessary research parameters, volumes, selected Sketch evidence and equations. Logs remove machine paths and personal user folders. No native CAD, compiled executable/DLL/PDB or original attachment is committed.

All 15 original Part hashes are compared to their original API-extraction hashes. Six AFJ source files in the user's active checkout are compared to saved baseline hashes; that checkout, its dirty work and branch remain intact. This solver patch exists only in a separate worktree based on R49. Source .csproj, other commands and deployment outputs are unchanged.

SOURCE_PROTECTION_AUDIT.json records the final comparison. REPORT_MANIFEST.csv hashes normalized LF text. Detached diagnostics/harness compilation is separate from the forbidden main Add-in Build/Rebuild/F5/Deploy operations.
