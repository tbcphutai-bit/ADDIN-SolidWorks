# R72 implemented rules and limits — API-qualified scope

Review date: 2026-10-31. The private workspace folder keeps its original 20261030 name. This document explains the frozen candidate source; actual API observations and completion status are in `API_EVIDENCE.json`. The root review qualified the six cases below; other geometries remain subject to runtime proof gates.

1. **Use the actual oblique member basis.** For unit longitudinal axes a and b, c = a dot b and D = 1 - c squared. For d = mate profile point - own profile point, the implemented intersection parameters are lambda = (d dot a - c times d dot b) / D and mu = (c times d dot a - d dot b) / D. The solver checks that both points coincide, remain on the measured zero-skin planes and, where required, lie within finite stock. It rejects parallel or ill-conditioned axes. A seam joins independently measured near and far intersections; its in-plane normal comes from the seam and actual sheet normal. This handles different widths and angles through measured boundaries, without assuming an orthogonal coordinate basis or a fixed 45-degree cut. Losing-side clearance shifts the solved seam by the required normal 0.10 mm, projected through the actual axis-normal dot product. See `NonOrthogonalMiterIntersection`, `NonOrthogonalMiterNormal` and `NonOrthogonalMeasuredMiter`.

2. **Accept equivalent families only with the same physical authority.** Equal cutoff values at one sample do not authorize choosing an arbitrary family. The frozen implementation requires the same native own/mating sheets, matching affine cutoff over the whole interval, compatible finite datums, inherited Bend paths and extension certificates. It records the complete equivalent-family set. Different physical authorities still stop with `UNVERIFIED_RULE`. `EQUAL_ENVELOPE_CERTIFIED` diagnostic counts in JSON show observed execution, not a count of unique rules or joints.

3. **Remove a secondary crossarm only when retained material proves it.** A named original flat-sheet mask must intersect the own original flat mask and the independently retained covering result with positive material volume. Connections to eligible families must follow measured native Bend chains. Bend continuation is certified using the actual native curved sector intersected with that named retained flat. A broad box, a visually overlapping line, or the losing Cut's newly generated face does not supply authority. Noncontact material has separate KEEP witnesses. See `CertifySecondaryOrthogonalObstruction`, `AddSecondaryMeasuredObstructions` and `CertifySecondaryBendContinuation`.

4. **Check the inner radius, not only the outer-radius projection.** In the measured 2222 case, Ri = 0.10 mm, Ro = 2.10 mm and assembly gap g = 0.10 mm. An outer-radius-only partial projection can leave an inner-radius clearance of g times Ri / Ro = 0.00476190476 mm, approximately 4.7619 micrometres. That is not the required 0.10 mm gap. Full-sector removal is allowed only by the bounded retained-edge certificate: the actual finite retained transverse boundary lies at the measured cylinder-center station, its complete inner-arc projection window contains retained material through the peer thickness, and the complete quarter-annulus witness belongs to original native stock. For this certified geometry the radial clearance is r times cos(theta); Ri = g makes every positive theta fail the gap at the inner radius, while the adjacent tangent remains exactly g away. The code requires the exact native Normal Cut oracle afterward. Ri different from g, a different annulus orientation, a hole, an end wedge or incomplete retained material does not inherit this conclusion. See `CertifySecondaryTangentGap` and `CertifyFullAnnulusRetainedEdge`.

5. **Give each Fold its own Blind Normal entry.** A sheet whose two adjacent measured Bends require opposite entry sides is split at the geometric midpoint of its original profile line. Each partition uses the measured entry of its own adjacent Bend. The split does not change the intended miter, the 0.10 mm fit gap or the Blind depth t + 0.10 mm. A dedicated native guide is attached to an existing Face2, its construction endpoints are Coincident with the two actual original-profile points, and an actual midpoint relation binds the exact standalone point to that construction line. The active and closed sketches must both read FullyConstrained status 3, have zero dangling/overdefining relations and retain both external source identities. No copied midpoint dimension, FIX, Convert Entities or new Plane supplies this boundary. See `PartitionMeasuredMiterCell`, `PartitionSecondaryEntryCell` and `R72WriteMeasuredMidpointGuide`.

6. **Compare Part and Assembly entities in their real contexts.** A native entity and an occurrence-context entity can have different COM wrappers. The implementation verifies actual document/feature ownership, the native scoped point or segment identity, corresponding Assembly entities and persistent reference equality where applicable. The midpoint must still resolve to the same owned closed sketch. This replaces a false rejection caused by wrapper identity alone; it does not accept coordinate coincidence as entity identity or relax Full3. Read-back graph checks remain mandatory.

7. **Attach the projected cap to unchanged original contour vertices.** Where the original end contour is axially staggered, the recipe first certifies its finite unchanged source contour. The construction cap uses the actual maximum axial Vertex and the two actual endpoint-height Vertices. Four geometric coordinate relations bind the two axial coordinates and two height coordinates to those native Vertices. Their definition identities are checked individually; the construction geometry must remain at the independently solved points and the closed sketch must reach Full3. This supplies geometric links without Convert Entities or a copied angle dimension. The source contour and production features are not edited to make the reference fit. See `R72ProjectedCapReference` and `PROJECTED_CAP_VERTEX_COORDINATES_VERIFIED`.

All operations retain the existing A/B selection and Preview chain. The smaller member keeps covering priority; unresolved coverage is reported, rather than assumed closed. Each applicable slice uses `NormalCut=true`, Blind end condition and API thickness plus `SheetCutOverrun = 0.10 mm`. `AssemblyFitGap = 0.10 mm` is a separate final-body condition. No Through All fallback is authorized by these rules.
