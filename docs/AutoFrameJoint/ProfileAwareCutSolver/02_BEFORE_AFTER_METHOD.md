Exact before MINUS after yielded removed bodies; Check2 and before=after+removed volume were checked. Rollback returned to end=1 and copies closed without save. All 42 pairs were verified. Original 15 source hashes remain unchanged.

43 Cuts in PR39 remain API_VERIFIED for existence, scalar values and parent Sketch geometry. This new rollback scope is 42: the independent 4114 Cut was not included. It is not an API extraction failure. Direct direction-reference getters still return -1/null, so 0 strict API-complete direction sets remain. Effective directions/closed side choices for 28 native replays are GEOMETRY_VERIFIED by exact after-body equivalence, not relabeled as API_VERIFIED.

28 line-profile native Cut oracles were replayed: 18 direct analytic prisms, 10 including measured NormalCut Bend relief. The other 14 closed curved profiles are hole/slot machining and were not promoted into corner rules. File/feature/ordinal, scalar parameters, Sketch and volumes remain in the JSON. Full stock face dumps, native BREP streams and CAD are kept local.

Eight T1/T2 corner comparisons use native before and after bodies only as test oracles. The candidate rule takes section geometry and relative placement; historical Feature ordinals select the oracle, never the production tool shape.
